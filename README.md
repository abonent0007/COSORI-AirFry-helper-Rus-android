# COSORI-helper-Rus-android
Удобный Калькулятор для расчета времени приготовления с учётом веса продукта или смешанных продуктов. С выбором желаемого результата. Справочник + рекомендаций с описанием ошибок. Приложение находится в разработке без исходников, скомпилированные APK файлом. является бесплатным программы обеспечением и не несёт ответственности за порчу оборудования для которого делалась, так как делал для себя и решил поделиться с другими.
